# 좀비 디펜스

HTML5 좀비 서바이벌 디펜스 게임. 세로 모드 전용, 설치 후 오프라인 실행 가능.

## 플레이
https://dangjoci.github.io/zombie-defence/

- **안드로이드(Chrome)**: ⋮ 메뉴 → 앱 설치
- **아이폰(Safari)**: 공유(□↑) → 홈 화면에 추가

## 조작
- 왼쪽 화면을 끌면 이동 (자동 공격)
- 오른쪽 아래 버튼: 건설 · 마을 · 연구 — 누르면 시간이 멈춥니다
- 건물을 탭하면 상세 창

## 업데이트
index.html만 교체하면 됩니다. 폰에서 반영이 안 되면 앱을 완전히 종료 후 재실행하세요.
